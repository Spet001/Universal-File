Spet's Universal Game File Opener

Universal in-browser game archive inspector, decompressor, and extractor running 100% locally via WebAssembly.

Supported Engine Formats

Inspect, extract, preview, and repack archives from over 25 game engines with zero server uploads: id Tech (WAD, PAK, PK3), Bethesda Softworks (BSA, BA2), Rockstar Games (RPF), Ubisoft (FORGE), Call of Duty FastFiles (T4-T10 & IW3-IW10), Nintendo DS (NDS NitroFS), Classic ROMs (GBA, N64, SNES, NES), Unreal Engine (PAK/UAsset), Square Enix (white_data), and raw RFC 1950 zlib deflate streams.

Key Capabilities

  • Local-First Zero-Upload Security: All binary parsing executes locally on your CPU via client-side WebAssembly.
  • 5-Zone Engineering Workstation: Virtual directory tree, lump table with sorting, integrated Hex viewer, asset previewer (audio, textures, scripts), and binary headers inspector.
  • Interactive Repacking: Rebuild modified game containers and transcode raw zlib streams.
